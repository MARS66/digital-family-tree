# 架构决策记录

本目录保存会长期影响产品、数据或工程结构的决策，避免重要判断只存在于对话或代码里。

## 何时新增 ADR

- 改变数据库、ORM、部署方式或模块边界。
- 改变核心实体、关系方向、审核或版本语义。
- 改变权限、隐私默认值或敏感字段处理方式。
- 引入重要基础设施、第三方服务或不可逆的数据迁移。

## 命名

`NNNN-short-title.md`，例如 `0001-select-orm.md`。

## 模板

```markdown
# ADR NNNN：决策标题

- 状态：提议 / 已接受 / 已废弃 / 已替代
- 日期：YYYY-MM-DD
- 负责人：

## 背景

为什么需要作出这项决定。

## 决策

选择了什么，以及明确不选择什么。

## 备选方案

考虑过哪些方案。

## 影响

正面影响、代价、风险和迁移要求。

## 验证

如何证明该决定在实际工程中成立。
```
