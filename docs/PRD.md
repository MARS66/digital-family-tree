# V1 MVP PRD

## 1. 产品目标

验证“分布式共建 + 集中审核”能否高效生成可信的家族关系数据。V1 围绕唯一核心闭环：

> 创建家族 → 建立主干 → 邀请/分支二维码 → 成员进入 → 人物认领 → 家庭补录 → 提交审核 → 正式生效 → 家谱扩张

## 2. 核心场景

### 场景一：创建者建立主干

创建者完成微信登录，创建家族，录入首个人物并可认领为自己，再录入若干已知祖辈/分支节点，形成可邀请的骨架。

### 场景二：成员认领与补录

成员从家族、分支或人物邀请进入，查看邀请上下文，搜索或选择谱中人物，提交认领；认领通过后，以自己或亲属为中心补录一个家庭单元。

### 场景三：管理员审核扩张

管理员查看贡献差异、来源、潜在重复和关系冲突；批准后以原子事务写入正式层，驳回或要求修改时保留记录。

### 场景四：批量导入骨架

管理员上传标准 Excel，完成列映射、预览、查重和冲突确认；确认的数据进入审核流程，绝不绕过人工确认直接成为事实。

## 3. V1 必须做

- 微信身份登录与会话。
- 家族创建、家族资料、成员与角色管理。
- Person 与 User 分离；跨家族认领。
- 人物增改查、未知人物占位、软删除与版本控制。
- 父/母/子女与伴侣关系的新增、校验、变更；兄弟姐妹推导。
- 家庭单元补录：本人/焦点人物、父母、伴侣、子女。
- 家族、分支、人物三种邀请链接/二维码及过期、撤销能力。
- 认领申请、审核、撤销/争议入口。
- 贡献草稿、提交、审核、批准、驳回、要求修改。
- 正式、待审核、历史版本三层数据语义。
- 来源记录、关键变更审计、冲突与重复提示。
- 三 Tab：“家族 / 共建 / 我的”。
- “以我为中心”、简化祖先、简化后代三种关系视图。
- 字段级隐私基础能力，敏感字段默认严格。
- Excel 模板导入、预览、人工确认；为 OCR/AI 保留接口。

## 4. V1 暂缓

- Word/PDF 自动解析、纸质谱 OCR 全自动入库。
- AI 自动判定关系或直接写入正式事实。
- 超大节点自由画布、完整世系全量一次渲染。
- 迁徙地图、完整时间轴、人物册、家族志、精排 PDF 出版。
- DNA、社交动态、商业化、公开家族搜索。
- Neo4j、复杂图算法、跨家族人物自动合并。
- 完整消息中心；V1 可用微信订阅消息加站内待办摘要。

## 5. 功能验收标准

1. 创建者可在 5 分钟内创建家族、首个人物和至少一条亲子关系。
2. 邀请链接/二维码能携带家族、分支或人物上下文，失效/撤销后不可继续使用。
3. 新成员能在 3 分钟内定位候选人物并提交认领；系统能阻止重复的有效认领。
4. 用户可围绕焦点人物添加父母、伴侣和子女，保存草稿并一次提交审核。
5. 审核前正式视图不变化；批准后整组变更原子生效；驳回保留理由和历史。
6. 系统拒绝自环、明显代际矛盾和祖先循环；并发修改不会静默覆盖。
7. 相似人物会产生查重候选，但未经人工确认不自动合并。
8. 合并后旧 ID 可解析至保留人物，关系与历史可追溯并可人工回滚。
9. 未获授权的用户无法通过接口读取敏感字段；界面隐藏不作为唯一保护。
10. 1000 人、3000 条关系规模下，焦点人物局部视图和列表的 P95 响应目标小于 1.5 秒（不含网络），所有列表分页。

## 6. 核心指标

- 北极星指标：每周新增的**审核通过且有来源/提交者记录的有效人物关系数**。
- 激活：创建家族后 24 小时内形成 ≥3 人、≥2 条关系并发出首次邀请的家族比例。
- 邀请转化：有效邀请访问 → 加入家族 → 提交认领的漏斗。
- 共建效率：新成员首次有效贡献耗时、每位活跃成员批准贡献数。
- 数据质量：重复候选率、冲突率、审核驳回率、合并后回滚率。
- 审核健康：待审核中位时长、超过 72 小时积压数。
- 留存：创建后第 7/30 天仍有新增有效人物或关系的家族比例。

指标不得以牺牲隐私、来源完整性或审核质量为代价。

## 7. 非功能要求

- 所有写操作鉴权、校验并记录审计上下文。
- 关键操作幂等；时间统一存 UTC，展示按用户时区。
- 数据导出和删除遵循授权与审计要求。
- 上传文件限制类型、大小，使用短期签名地址并进行安全扫描。
- 日志不记录电话、地址、证件等敏感明文。
