# MVP 范围、里程碑与完成定义

## 范围边界

V1 验证三件事：关系模型正确、协作闭环可运行、正式数据可信。视觉丰富度、自动化识别和出版能力让位于这三项。

| 能力     | V1                           | 后续                     |
| -------- | ---------------------------- | ------------------------ |
| 身份     | 微信登录、User/Person 分离   | 多端账号合并             |
| 关系     | 亲子、伴侣、兄弟姐妹推导     | 收养/监护等更细法理类型  |
| 共建     | 邀请、认领、家庭补录、审核   | 智能任务编排             |
| 导入     | Excel 模板、人工确认         | Word/PDF/OCR/AI          |
| 展示     | 以我为中心、祖先/后代简图    | 全谱、地图、时间轴、出版 |
| 数据治理 | 来源、版本、冲突、查重、合并 | 跨家族实体消歧           |

## 阶段完成定义

### M0：规格冻结

- 核心术语、实体边界、权限和审核状态一致。
- API 草案覆盖核心闭环。
- 每个开发任务有依赖、验收与测试。

### M1：底层模型与 API

- 数据库迁移可重复执行。
- 可创建 A、B 并把 B 设为 A 的父/母；读取结果正确。
- 自环、祖先循环、重复边和并发覆盖有自动化测试。
- 正式、待审核、历史三层可被证明互不混淆。

### M2：创建家族

- 登录 → 创建家族 → 创建首个人物 → 认领自己 → 进入家族首页闭环可演示。
- 创建者权限、失败回滚、重复提交和空状态已覆盖。

### M3：家庭补录

- 围绕焦点人物补父母/伴侣/子女，支持未知占位和来源。
- 草稿不影响正式谱；提交后形成可审查差异包。

### M4：邀请、认领与审核

- 三类邀请可生成、过期、撤销。
- 成员加入、认领、贡献、审核、正式生效端到端跑通。
- 权限拒绝、重复候选、冲突、驳回/修改均有状态呈现。

### M5：关系可视化

- 三种局部视图按权限过滤后渲染。
- 1000 人数据集下按需加载，不一次获取全家族节点。

### M6：大规模补谱与导入

- Excel 下载模板、上传、映射、预览、查重、冲突、人工确认闭环。
- 批处理可恢复，错误可定位到行；导入不绕过审核。

## 发布门槛

- 核心闭环 E2E 全绿；权限矩阵和循环检测测试全绿。
- 无高危安全缺陷；敏感字段无越权读取。
- 数据备份恢复演练成功；迁移有回滚方案。
- 产品、工程、测试共同完成 1000 人样本验收。
