# Codex 可执行任务清单

## 执行规则

- 一次只领取一个任务；禁止“一次性开发完整小程序”。
- 开工前阅读本任务依赖的文档，先报告范围和不做项。
- 每个任务交付代码、迁移、必要文档、自动化测试和验证命令。
- 不擅自改变实体语义、权限、审核状态或隐私默认值；发现冲突先更新决策记录。
- 测试必须使用隔离数据库；不得只用 mock 证明数据库约束。

## 0. 工程基础

### T001 初始化仓库与质量门禁

- 依赖：规格文档。
- 范围：建立 `miniprogram/`、`server/`、`database/`（迁移可归 server）、共享契约目录；TypeScript、lint、format、test、CI。
- 不做：业务页面和实体。
- 验收：全新环境按 README 可启动；lint/typecheck/test 一条命令全绿；环境变量有示例且无密钥。
- 测试：CI smoke test。

### T002 建立 PostgreSQL 与迁移框架

- 依赖：T001；阅读 `DATA_MODEL.md`。
- 范围：选定 Prisma 或 Drizzle，配置本地测试库、迁移、种子框架、事务测试工具。
- 验收：空库升级到最新、回滚策略有说明、测试间数据隔离。
- 测试：迁移从零执行；唯一约束样例。

### T003 API 基础协议

- 依赖：T001。
- 范围：HTTP 服务、`/health`、统一响应/错误、trace ID、校验、幂等中间件骨架、OpenAPI。
- 验收：错误结构与 `API_SPEC.md` 一致；重复幂等键返回相同结果或明确冲突。
- 测试：单元 + HTTP 集成。

## 1. 身份、家族与人物本体

### T010 微信登录适配层

- 依赖：T002、T003。
- 范围：微信 code 交换接口抽象、User/会话表、开发环境 fake provider。
- 验收：同一 OpenID 幂等得到同一 User；token 轮换与注销有效。
- 测试：provider 契约、会话过期、重复登录。

### T011 Family 与 Membership

- 依赖：T010。
- 范围：Family、FamilyMembership 模型与创建/读取；创建者 OWNER。
- 验收：创建原子化；跨 family 读取返回 404/403；同用户成员关系唯一。
- 测试：租户隔离、幂等创建、事务回滚。

### T012 Person 基础模型

- 依赖：T011。
- 范围：Person CRUD 领域层、日期精度、占位、软删除、version。
- 验收：未知值不用假日期；版本冲突返回 409；合并状态暂只预留。
- 测试：日期校验、占位规则、软删除查询、乐观锁。

### T013 亲子关系与循环检测

- 依赖：T012。
- 范围：Relationship(PARENT_OF)、双向读取、兄弟姐妹推导、循环检测。
- 验收：A→B 父子可创建与读取；自环、重复、祖先循环被拒绝；两端必须同 Family。
- 测试：真库集成、随机图属性测试、并发插入测试。

### T014 伴侣关系

- 依赖：T012。
- 范围：PartnerUnion、规范化端点、起止日期、查询。
- 验收：A-B 与 B-A 不能重复；不自动推断亲子。
- 测试：唯一、自环、跨家族、软删除后重建。

## 2. 创建家族闭环

### T020 创建家族组合 API

- 依赖：T011、T012。
- 范围：一次创建 Family + OWNER + 首 Person + 可选 self claim。
- 验收：任一步失败全部回滚；弱网重试不重复创建。
- 测试：事务、幂等、输入校验。

### T021 小程序登录与首次选择

- 依赖：T010、T020。
- 范围：登录、无家族空状态、创建/加入入口、会话恢复。
- 验收：新用户能走到创建家族；错误可重试且不丢表单。
- 测试：页面组件 + 关键 E2E。

### T022 创建家族与首页

- 依赖：T021。
- 范围：创建表单、首人物、认领选项、家族首页摘要、家族切换。
- 验收：5 分钟内完成闭环；切换时不闪现上一家族数据。
- 测试：E2E、空/错/加载状态。

## 3. 贡献、审核与家庭补录

### T030 Contribution 状态机

- 依赖：T012、T013、T014。
- 范围：Contribution/Item、草稿保存、提交、撤回；schema 校验。
- 验收：草稿不改变正式层；非法状态转换拒绝；item 幂等。
- 测试：全部状态转换、权限、版本冲突。

### T031 Source 与 Revision

- 依赖：T030。
- 范围：Source、Revision/Change；批准应用服务基础。
- 验收：每项批准变更可回答谁/何时/前后值/来源；历史追加写。
- 测试：快照完整性、历史不可更新、事务失败不留半条记录。

### T032 Review 与原子批准

- 依赖：T031。
- 范围：审核队列、决定、批准时重校验并原子写正式层和历史。
- 验收：并发只允许一个有效决定；冲突返回 409；驳回不改正式层。
- 测试：两管理员并发、循环在提交后形成、版本已变化。

### T033 家庭单元补录 API

- 依赖：T030。
- 范围：围绕焦点人物组合添加父母/伴侣/子女、占位、来源。
- 验收：整组保存为一个 Contribution；返回逐项重复/冲突提示。
- 测试：混合新增/关联现有人物、部分失败、幂等。

### T034 家庭补录与审核页面

- 依赖：T032、T033。
- 范围：家庭表单、草稿、差异、审核队列/详情。
- 验收：普通成员完成提交；管理员批准后视图变化；各状态文案明确。
- 测试：组件、E2E、并发冲突恢复。

## 4. 邀请、分支、认领与权限

### T040 权限决策引擎

- 依赖：T011。
- 范围：角色 ∩ 资源范围；集中式 policy API。
- 验收：所有现有接口接入；默认拒绝；跨 Family 永不放行。
- 测试：权限矩阵表驱动测试。

### T041 Branch 与分支管理员

- 依赖：T040、T012。
- 范围：Branch、PersonBranch、BranchMembership；循环保护。
- 验收：分支管理员只能处理本分支资源；人物可多支关联且有主支。
- 测试：范围、唯一、Branch 循环。

### T042 三类 Invitation

- 依赖：T041。
- 范围：token 哈希、预览、接受、过期/次数/撤销、二维码 payload。
- 验收：二维码无敏感数据；接受幂等；无效 token 不披露家族细节。
- 测试：生命周期、并发最后一次使用、越权创建。

### T043 PersonClaim

- 依赖：T032、T040。
- 范围：认领申请、审核、撤销/争议；部分唯一约束。
- 验收：跨家族可多认领；同 Family/Person 有效本人认领规则成立；占位不可认领。
- 测试：并发批准、重复申请、撤销后再申请。

### T044 邀请/认领小程序闭环

- 依赖：T042、T043。
- 范围：落地页、搜索候选、认领、状态、分享卡/二维码。
- 验收：从微信分享进入可完成加入和认领；过期与已认领状态可理解。
- 测试：核心 E2E、深链恢复、登录中断恢复。

## 5. 隐私与 View

### T050 字段级隐私服务

- 依赖：T040、T043。
- 范围：PrivacySetting、继承优先级、亲缘范围计算、响应序列化。
- 验收：敏感字段在 API 层不可越权读取；本人可收紧范围。
- 测试：各范围表驱动、三代边界、无认领、隐藏字段不进日志。

### T051 局部家谱 View API

- 依赖：T013、T014、T050。
- 范围：self/ancestors/descendants，深度限制、cursor、隐藏节点占位。
- 验收：不会全量拉取；已合并 ID 可解析；结构不泄密。
- 测试：1000 人/3000 边性能、循环脏数据降级、权限快照。

### T052 三 Tab 与局部家谱 UI

- 依赖：T051、T034、T044。
- 范围：家族/共建/我的壳、三种局部视图、人物详情状态。
- 验收：按需展开流畅；待审不冒充正式；所有空/错/无权状态齐全。
- 测试：组件、视觉回归、主流程 E2E。

## 6. 数据质量与导入

### T060 重复候选服务

- 依赖：T012、T031。
- 范围：规则化候选分数与 signals；人工标记非重复。
- 验收：不自动合并；同一人物对不重复建候选；可解释信号。
- 测试：姓名/日期/亲属组合、端点规范化。

### T061 人物合并预览与执行

- 依赖：T060、T032。
- 范围：MergeRecord、预览、审核、事务迁移、旧 ID 重定向。
- 验收：不会生成自环/重复边；冲突阻断；历史和来源保留；可安全时支持反向修订。
- 测试：复杂关系、认领冲突、并发、失败回滚。

### T062 Excel 模板与安全上传

- 依赖：T003、T041。
- 范围：版本化 xlsx 模板、COS 私有上传、Media、文件校验。
- 验收：类型/大小/权限受控；公式注入被清理或拒绝；短期签名。
- 测试：恶意扩展名、超限、重复文件、过期签名。

### T063 ImportJob 解析与映射

- 依赖：T062、T060。
- 范围：状态机、列映射、逐行规范化、错误、查重与关系候选。
- 验收：错误定位到行列；任务可重试/恢复；大文件异步分页查看。
- 测试：标准/缺列/混合日期/重复/中断恢复。

### T064 导入人工确认与审核

- 依赖：T063、T032。
- 范围：逐行决定、冲突处理、确认后生成 Contribution。
- 验收：任何导入数据均不直接入正式层；每行决定可追溯。
- 测试：部分接受、关联现有人物、审核驳回、重复确认幂等。

### T065 导入小程序页面

- 依赖：T064。
- 范围：模板、上传、映射、预览、错误筛选、确认和进度。
- 验收：管理员能完成一次含错误行和重复候选的导入。
- 测试：E2E、后台任务轮询/恢复、权限。

## 7. 发布准备

### T070 审计、安全与可观测性加固

- 依赖：所有核心模块。
- 范围：审计覆盖清单、敏感日志检查、限流、上传扫描、指标告警。
- 验收：关键操作 100% 有 actor/family/action/trace；无敏感明文日志。
- 测试：安全回归、权限模糊测试、日志断言。

### T071 备份恢复与迁移演练

- 依赖：T070。
- 范围：备份、PITR/恢复、迁移回滚手册。
- 验收：在隔离环境恢复到目标时间点并核对人物/关系/历史数量。
- 测试：记录演练时间和结果。

### T072 MVP 端到端验收

- 依赖：T052、T061、T065、T071。
- 范围：1000 人样本，完整核心闭环、权限矩阵、性能和失败恢复。
- 验收：满足 `PRD.md` 与 `MVP_SCOPE.md` 发布门槛；已知限制成文。
- 测试：自动 E2E + 人工验收清单，输出报告。
