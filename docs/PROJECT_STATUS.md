## 已冻结的关键决策

- 产品是家族数字档案、关系网络与协作共建平台。
- PostgreSQL 是 V1 事实数据库；暂不使用 Neo4j。
- 使用独立 Node.js/TypeScript 后端；微信小程序为前端。
- `User` 与 `Person` 分离，通过 `PersonClaim` 关联。
- 正式、待审核、历史版本三层数据语义不可混淆。
- 家谱展示采用局部按需加载，V1 不挑战完整超大节点画布。
- Excel 是 MVP 导入方式；Word/PDF/OCR/AI 仅预留扩展。
